*** Types of Java Platform
  1] Java standard Edition Platform

       - It is also called as Java se platform / core java
       - Standalone Application => which do not follow client/ server architecture
       - Using features of Java SE platform we can develop execute standalone application
       - Using Java SE/ core Java, we can develop CUI, GUI, Library application (.jar) and Network application
  2] Java Enterprise Edition Platform

       - It is called as Java EE/ JEE/Enterprise java/ Advanced Java
       -client - It is a program which consumes service provided by server
                 1] Smart client => Mobile Application
                 2] thin client / Web Client / Http client => web browser
                 3] Thick Client => Desktop application
        - A machine on which we deploy/ install client program

        - server: It is server ehich provide service to client
                1] web server : apache tomcat
                2] application Server: apache TomEE, ,Glassfish, Jboss , webLogic
                3] A machine on which we deploy / install server program
                4] Java EE platform provides features to develop and run client server application
  3] Java Micro edition platform
        - It is also called as Java ME
        - it is used to develop and deploy application for consumer devices
        - Example : Mobile Phone, set top box , washing machine etc
